# Phoenix 실습 1문제 — Stack Zero (로컬 실행 원칙)

> 문제는 링크만 제공한다. 문제 바이너리·풀이 코드·페이로드는 이 저장소에 포함하지 않는다.

- 문제 링크: https://exploit.education/phoenix/stack-zero/
- 출제자 사이트(Exploit Education Phoenix)의 안내에 따라 로컬 VM/컨테이너에서 실습할 것.

## 원칙

1. **로컬 실행 원칙**: 실습은 `pwn/Dockerfile`로 빌드한 로컬 컨테이너 안에서만 수행한다.
2. **원격 익스플로잇 금지**: 외부 서버·타인 소유 시스템 대상 익스플로잇 전송을 금지한다.
3. **페이로드 게시 금지**: 완성된 익스플로잇·쉘코드를 보고서·커밋에 포함하지 않는다. 재현 절차는 단계 서술로만 기록한다.

## 진행 방법

1. 컨테이너 빌드·실행은 사용자가 직접 수행 (이 작업에서는 파일 작성까지만 함).
2. Phoenix Stack Zero 문제를 로컬에 구성하고 `gdb + pwndbg`로 동작을 관찰한다.
3. `pwn/exploits/`에는 성공 여부·관찰 기록(한국어 메모)만 남기고, 실제 공격 코드는 별도 보관하거나 포함하지 않는다.
