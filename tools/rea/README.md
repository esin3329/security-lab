# REA 도구 안내 (Stub, Phase 2 예고)

> 본 문서는 REA(Reverse Engineering Assistant) 도구 연계를 위한 스텁(Stub) 안내 문서입니다.

## 1. 개요

- REA는 바이너리 분석 및 리버스 엔지니어링 보조 도구로 security-lab 평가 대상 중 하나로 검토 중입니다.

## 2. MVP 상태 및 범위 제한

- **MVP 제외:** 현재 MVP 단계에서는 REA 도구의 구현, 스크립트 작성, 빌드 및 실행을 수행하지 않습니다.
- **착수 금지:** MVP 기간 중에는 Phase 2 구현 작업을 진행하지 않으며, 폴더 내 추가 파일 작성을 제한합니다.

## 3. Phase 2 도입 계획 (예고)

- Phoenix 바이너리 및 pwn 실습 환경과의 연계 분석 도구로 도입을 검토합니다.
- Strix 및 수동 점검 체계의 8지표 평가 방식이 확정된 이후, 동일한 평가 기준에 맞추어 점검 인터페이스를 설계할 예정입니다.
- 로컬 격리 컨테이너 환경 내에서의 안전한 실행 및 출력 제어 방안을 마련한 후 구현에 착수합니다.
