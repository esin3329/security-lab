# ARTEX-KO 도구 안내 (Stub, Phase 2 예고)

> 본 문서는 ARTEX-KO(한국어 보안 점검 및 레드팀 보조 도구) 연계를 위한 스텁(Stub) 안내 문서입니다.

## 1. 개요

- ARTEX-KO는 한국어 취약점 점검 및 설명가능성 평가를 위한 도구로 security-lab 평가 대상 중 하나로 검토 중입니다.

## 2. MVP 상태 및 범위 제한

- **MVP 제외:** 현재 MVP 단계에서는 ARTEX-KO의 구현, 래퍼 스크립트 작성, 외부 모델 연동 및 실행을 수행하지 않습니다.
- **착수 금지:** MVP 기간 중에는 Phase 2 구현 작업을 진행하지 않으며, 폴더 내 추가 파일 작성을 제한합니다.

## 3. Phase 2 도입 계획 (예고)

- Juice Shop 단일 대상 및 정답지(ground-truth) 확정 이후, Strix와의 지표 비교 대상 도구로 연동을 검토합니다.
- 한국어 보고서 생성 및 설명가능성(루브릭 1~5점) 측정 프레임워크와의 결합 방안을 수립합니다.
- 외부 API 호출 통제 및 결과 로그의 민감 정보 필터링 구조를 마련한 후 본격적인 개발을 진행할 예정입니다.
