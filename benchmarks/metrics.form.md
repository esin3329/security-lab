# 벤치마크 지표 기록 양식 (완결 벤치마크 보조 기능, 8개 지표)

> 스키마 원본: `metrics.schema.json`. 본 양식은 완결된 8지표 벤치마킹 측정을 위한 보조 양식이며, 프로젝트 주 목표인 CTF 깃발 획득이나 KoTH 실습의 선행조건이 아닙니다.  
> CTF 플래그 획득이나 KoTH 점유 기록은 본 양식 및 스키마에 넣지 않으며 `logs/` 내 별도 Markdown 관찰 메모로 관리합니다.  
> 벤치마크 조건: 동일 타겟·동일 시간제한(scanner attempt 최대 900초)·3회 반복 (KoTH 로컬 15분 훈련 라운드와 완전히 별개).

## 기록표 (벤치마크 보조 실측 시 사용)

| run_id | 일시(UTC) | 도구@버전 | 타겟(host:port) | 반복(n/3) | ①TP | ②FP | ③PoC성공률 | ④실행시간(초) | ⑤토큰/비용(USD) | ⑥사람개입(회/분) | ⑦재현성 | ⑧설명가능성(1-5) | 비고 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 형식 예시(실측 아님) | UTC 시각 | 도구@확인된 고정버전 | 승인된 host:port | n/3 | 판정유보 | 판정유보 | 시도 없음 | 미측정 | 미측정 | 미측정 | 판정유보 | 미측정 | 사유 및 안전한 관찰 메모 경로 |

## 지표 정의 (요약)

1. **TP**: ground-truth와 대조해 확정된 참 탐지 수.
2. **FP**: 오탐 수.
3. **PoC성공률**: 성공 PoC 수 ÷ 시도 PoC 수 (0~1).
4. **실행시간**: 래퍼 시작~종료까지 초 단위 (준비/정리로 900초를 초과할 수 있으며 15분 대상 작업 상한과 구별).
5. **토큰/비용**: LLM 사용 토큰 수 + API 비용(USD).
6. **사람개입횟수**: 실행 중 사람이 개입한 횟수(선택: 개입 시간 분 단위 병기).
7. **재현성**: 동일 조건 재실행 결과. `재현 성공` / `부분 재현` / `재현 실패` 중 택1.
8. **설명가능성**: 결과 설명의 명확성 1~5점 (1=불명확, 5=재현 가능한 수준의 명확한 설명).

## JSONL 기록 조건 (완결 벤치마크 전용)

- 통합된 `benchmarks/metrics.schema.json` 및 `tools/strix/metrics.py`는 고유 `run_id`, RFC 3339 달력상 유효 UTC `timestamp`, `tool`/고정 `tool_version` 형식, allowlist 3개와 정확 일치하는 `target`, `time_limit_min: 15`, `repeat_index: 1~3` 및 결측 없는 8개 지표를 모두 필수로 강제합니다.
- 환경 요구사항은 `tools/strix/requirements.txt`의 `jsonschema==4.19.2`와 POSIX flock을 지원하는 Linux/WSL 환경입니다.
- 중복 object key, 중복 `run_id`, 잘린 로그, 비유한 숫자는 거부되며, append-only 롤백 및 동시성 락이 보장됩니다.
- 표의 `미측정`/`판정유보`/`시도 없음`은 상태 표기이며 JSON 스키마의 지표 값이나 새 enum이 아닙니다. 스키마에는 결측치 표현이 없으므로 결측치가 있는 실행은 안전한 Markdown 관찰 메모로 남깁니다.
- 미시도 PoC·미수집 토큰/비용·미확정 TP/FP를 0으로 대체하거나 3회 검증 없이 재현 성공을 기록하지 않습니다. 확정된 기록 CLI 인터페이스는 `python3 tools/strix/metrics.py --record <완결 JSON 파일> --output <JSONL 파일>` (종료 코드 0: 성공 및 fsync, 2: 거부)이며 `/tmp` smoke 테스트로 검증되었습니다 (실측값 아님). 자동 JSONL 기록은 현재 래퍼에 미구현입니다.
- **게임 기록 분리:** CTF/KoTH 게임 결과는 본 스키마에 기록하지 않습니다.

## ground-truth 대조 방법

- `ground-truth/juice-shop-v17.1.1.json`은 `findings: []`인 미확정 스텁입니다. 빈 배열은 취약점 0건을 뜻하지 않으며 TP/FP 판정과 8지표 완결 비교는 차단 상태입니다.
- 정답 내용 확정은 Phase 2로 이월합니다. 확정 이후에만 안전한 실행 기록과 ground-truth를 대조해 사람이 TP/FP를 판정합니다.
- **선행조건 아님:** ground-truth 미확정은 8지표 비교의 차단 사유일 뿐이며, 독립적인 CTF 플래그 판정이나 KoTH 점유 실습의 선행조건이나 차단 사유가 아닙니다.
